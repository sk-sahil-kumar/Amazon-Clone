🛒 Amazon Clone

A simple and responsive Amazon-inspired website built using HTML5 and CSS3.

📌 About the Project

This project is a front-end clone inspired by Amazon's e-commerce website. It recreates the look and feel of an online shopping platform using HTML for structure and CSS for styling.

The project was developed to strengthen my understanding of web development fundamentals, page layouts, and responsive design.

✨ Features

- 🏠 Amazon-inspired homepage design
- 🔍 Search bar UI
- 📦 Product categories and product cards
- 🖼️ Product images and promotional banners
- 🎨 Styled navigation bar and footer
- 📱 Responsive layout (where implemented)

🛠️ Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling, layouts, and visual design

📂 Project Structure

Amazon-Clone/
├── index.html
├── style.css
├── images/
└── README.md

🚀 How to Run

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder.

3. Open "index.html" in your web browser.

No additional dependencies or installations are required.
